# trillium-seed (the core for trilliumOS)

**trillium-seed** is a custom-built bootc image that serves as the core of the trilliumOS Linux operating system. It is built on Rocky Linux, integrates the latest Linux LTS kernel derived from the Fedora Enterprise Linux Next (ELN) source RPM, and provides native support for Btrfs.
